# 🏠 Bank System Project Part 01
---

# 📄 Overview

Bank System Project is an educational project that simulates a simple banking system. The program allows users to perform essential operations on clients within the banking system through an easy-to-use text-based interface.
---

# ⚙️ Features

- 📋 User Input Handling: Reads customer information entered by the user.
- 👤 Add New Client: Allows the user to add new clients to the system.
- ✏️ Edit Client Information: Enables modification of existing client data.
- ❌ Delete Client: Allows the user to remove clients from the system when needed.
- 📄 Display Results: Presents client information and system operations in a clear and organized format.
- ---

# 🧱 Project Structure (Part One)

This first part of the project includes:

1- User input handling components.

2- Basic CRUD functionalities (Create – Read – Update – Delete).
